# 图片水印工具

批量给图片添加文字或 Logo 水印。**纯前端实现，图片不会上传到任何服务器**，断网也能用。

- 入口：`tools/image-watermark/index.html`（双击即可打开）
- 版本：v1.0.0

## 功能

- **两种水印模式**：文字水印、图片（Logo）水印
- **样式完全可控**：内容、字体（9 种）、加粗/斜体、字号、颜色（含快捷色板）、不透明度、旋转角度，
  另提供描边与投影，避免水印在浅色照片上"消失"
- **两种排布**：九宫格 9 个方位任选，或**平铺全图**（可调横纵间距、支持交错排列）用于防截图盗用
- **批量处理**：多张一起导出，自动打包成 ZIP 下载，带进度提示
- **格式兼容**：导入 JPG / PNG / WebP / BMP / GIF；导出可选保持原格式，或统一转 JPG / PNG / WebP
- **质量无损**：按原图分辨率离屏重绘后再导出，不做任何缩放；PNG 为无损导出
- **自适应缩放**：水印尺寸默认按图片短边百分比计算，1000px 与 4000px 的图片水印占比自动一致
- **配置方案**：常用配置可命名保存、下拉一键切换；内置 4 套模板；支持 JSON 导入导出（备份 / 跨设备迁移）

## 使用方法

1. 打开 `index.html`
2. 左侧**添加图片**：点击选择、拖拽文件进来，或直接 `Ctrl+V` 粘贴
3. 中间点任意图片切换预览（右上可切换"显示/隐藏水印"对比效果）
4. 右侧调参数，**预览实时更新**
5. 导出：
   - 「导出当前图片」—— 只导出预览中的那张
   - 「批量导出全部（ZIP 打包）」—— 处理列表里的所有图片并打包下载

> 设置会自动保存在浏览器本地（localStorage），下次打开仍在。「恢复默认」可一键还原。

### 配置方案

右侧面板顶部的「配置方案」用来管理多套参数：

| 操作 | 说明 |
|---|---|
| 下拉选择 | 内置模板（只读 4 套）与「我的方案」分组，选中即应用 |
| 存为新方案 | 把当前参数存成一套命名方案，重名自动加序号 |
| 覆盖保存 / 重命名 / 删除 | 仅对「我的方案」可用，内置模板按钮自动禁用 |
| 导出 JSON | 把当前参数导出为 `.json`，可备份或发给别人 |
| 导入 JSON | 兼容三种格式：单套 `{name,cfg}`、裸配置对象、方案数组 `[...]`，缺失字段自动用默认值补齐 |

- 选中方案后再改参数，下拉会显示「· 已改动」，刷新页面仍保留你的改动（不会被方案覆盖）；
  想存回去点「覆盖保存」，想另起一套点「存为新方案」。
- **Logo 图片本身不进配置**：图片水印只保存尺寸/透明度等参数，切换方案后需重新选择 Logo。
- 存储键：`wm_cfg`（当前参数）、`wm_presets`（方案库）、`wm_preset_active`（当前方案）、`wm_preset_dirty`（已改动标记）。

## 参数说明

| 参数 | 说明 |
|---|---|
| 字号 / Logo 宽度 | 单位可选 `%`（相对图片短边，随图片大小自适应，推荐）或 `px`（固定像素） |
| 不透明度 | 1%~100%，防盗图水印建议 20%~40% |
| 旋转角度 | -180°~180°，平铺场景常用 -30° 或 -45° |
| 平铺间距 | 相对水印自身尺寸的百分比，越大越稀疏 |
| 交错排列 | 隔行偏移半个身位，即使被裁掉一行也不影响防盗效果 |
| 边距 | 九宫格模式下水印距图片边缘的距离 |
| 输出质量 | 仅对 JPG / WebP 生效，推荐 0.90~0.95（肉眼几乎无损）；PNG 始终无损 |

## 实现要点

- 渲染核心是 Canvas 2D。所有尺寸统一经 `unitOf(value, unit)` 换算，`%` 基于图片短边、`px` 乘缩放系数
  `s = 目标宽 / 原图宽`，因此**预览（缩略）与导出（原尺寸）的视觉完全一致**——改动渲染逻辑时需保持这一点。
- 导出时新建与原始分辨率相同的离屏 canvas 重绘，不缩放；JPG 导出前先填白底，避免透明区变黑。
- ZIP 打包为**自行实现的 store 模式**（CRC32 + local header + central directory + EOCD，文件名用 UTF-8 flag），
  不依赖 JSZip 等库，已通过 Python `zipfile` 校验。
- `file://` 下极少数浏览器会污染 canvas，导出前有探测逻辑，失败时自动降级为 dataURL 重新加载。

## 兼容性

Chrome / Edge / Firefox / Safari 现代版本。WebP **导出**依赖浏览器的 `canvas.toBlob('image/webp')`，
若浏览器不支持会自动回退为 PNG。
