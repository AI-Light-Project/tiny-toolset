# 大语言模型斩杀线

把各家大模型的「成本 × 表现」画成一张散点图。**点中任意一个模型**，它会射出十字参考线把图切成四个象限，
左上角（成本更低 + 表现更好）里的所有模型就是能「斩杀」它的竞品。

- 入口：`tools/llm-kill-line/index.html`（双击即可打开）
- 版本：v1.0.0

## 数据来源（重要）

| 项 | 说明 |
|---|---|
| 来源 | [Artificial Analysis](https://artificialanalysis.ai/zh/leaderboards/models) 模型榜单 |
| 口径 | 内置快照为抓取该榜单页的 `models` 数据集后精简：仅保留**未废弃**且**有智能指数**的模型 |
| 实时抓取 | 页面打开后会尝试直接 `fetch` 榜单页（该页返回 `Access-Control-Allow-Origin: *`，浏览器可跨域读取），解析 Next.js 的 RSC 载荷后替换数据 |
| 失败回退 | 离线 / 被墙 / 页面改版解析失败时，**自动回退到内置快照**，并在右上角徽标与页脚写明「实时抓取失败 · 用内置快照（日期）」 |
| 标注 | 右上角徽标始终显示当前数据来源与时间（实时抓取显示到分钟，快照显示快照日期） |

内置快照生成于 **2026-09-19**，含 272 个模型、56 家厂商，AA 智能指数版本 v4.3。

## 功能

### 1. 模型筛选（左栏）
- **按厂商多选**：色块 + 名称 + 该厂商模型数，点击切换；勾选框颜色即该厂商在散点图中的颜色
- **搜索**：匹配模型名 / 简称 / 厂商 / slug
- **全选 / 清空 / 仅主流**：仅主流 = 主流厂商 ∪ 模型数 ≥ 8 的厂商
- 筛选结果实时反映到图表，图表上方徽标同时提示「隐藏 N」—— 有多少模型因当前轴缺数据而未绘制

### 2. 坐标轴（顶部工具条）
**X 轴 —— 成本**（可切换，每项在图表上方都有文字说明）

| 选项 | 含义 |
|---|---|
| 混合价（默认） | `(3 × 输入价 + 1 × 输出价) ÷ 4`，USD / 百万 tokens。按输入 token 占多数的一般对话负载折算 |
| 输入价 | prompt 计价，USD / 百万 tokens |
| 输出价 | completion 计价，USD / 百万 tokens |
| 每任务成本 | Artificial Analysis 用固定评测任务实测的综合成本，已含思考 token 与缓存折扣，USD / 任务 |

**Y 轴 —— 表现**：12 项可选，默认 **AA 智能指数 v4.3**，另有 GPQA Diamond、Humanity's Last Exam、τ²-bench、
Terminal-Bench Hard、SciCode、IFBench、CritPt、MMMU-Pro、GDPval、AA-Omniscience、输出速度。

**刻度**：X / Y 可各自切换对数刻度（价格跨 3 个数量级，默认 X 轴开对数）。

**其他**：同家族连线（把同一模型 low→max 不同推理强度的变体连起来，看「多花钱多思考」的边际收益）、重置视图。

### 3. 交互
- **悬停**：显示模型名、厂商、当前 X/Y 轴数值、输入/输出价、每任务成本、输出速度、上下文长度；若已选中对比对象，还会提示两者互斩关系
- **缩放 / 平移**：滚轮以光标为中心缩放，拖拽平移，触屏支持双指缩放
- **图例**：图表上方按当前可见模型列出「颜色 = 厂商」及模型数

### 4. 斩杀线（右栏）
点击任一模型后：

- 以该点为原点画出**平行于 X 轴**与**平行于 Y 轴**的参考线，把图切成四个象限
- 高亮 **左上象限**（成本更低 + 表现更好）= 斩杀区，并在图上标注四象限含义
- 右栏列出斩杀区内全部模型，按表现降序，每项显示分数提升与相对便宜幅度；点击可把该模型设为新的斩杀对象
- 支持**取消选中**（再次点击同一点 / 点空白处 / 按 Esc / 点「取消选中」）与**切换对比对象**（直接点另一个模型）
- 同时给出「被它反杀」的数量（右下象限：更贵且更弱）

> 斩杀集合只在**当前筛选范围**与**当前坐标口径**内计算 —— 换轴或改筛选，结论会跟着变。

## 实现要点

- **无依赖**：散点图是原生 SVG 手绘（无 D3 / ECharts）。坐标变换统一走
  `fx(v)`（按需 log10）→ 像素；`state.view` 保存的是**变换后**的数据范围，因此缩放、平移、对数切换共用同一套逻辑。
- **对数轴刻度**：按 `1 / 2 / 5 × 10ⁿ` 生成；数据里的 0 与 null 一律视为「无数据」并过滤（AA 对未跑的评测给 0，也按缺失处理）。
- **实时抓取解析**：榜单页数据藏在 `self.__next_f.push([1,"..."])` 的流式载荷里。解析步骤：
  ① 正则取出所有 push 分片并逐个反转义后拼接；② 在拼接结果里定位 `"models":[` 并用**括号匹配**（跳过字符串内的括号）取出数组；
  ③ 取**包含 `intelligenceIndex` 字段**的那个数组（页面里有多个同名数组）。
- **测试**：`app.js` 末尾暴露 `window.__KILL__`（state / extractModels / normalize / visibleModels / xVal / yVal / render / selectModel），
  便于用 mock DOM 跑离线断言。

## 更新内置快照

`data.js` 就是一份精简后的快照（`window.AA_SNAPSHOT`）。字段说明：

```js
{
  id,   // slug
  n,    // 显示名（shortName）
  r,    // 发布家族名，用于「同家族连线」
  c,    // 厂商
  o,    // 1 = 开源权重
  ctx,  // 上下文窗口 tokens
  idx,  // AA 智能指数
  cost, // 每任务成本 USD
  in, out, // 输入 / 输出价，USD / 百万 tokens
  tps,  // 中位输出速度 tok/s
  bm: { gpqa, hle, tau2, tbHard, scicode, ifbench, critpt, mmmuPro, gdpval, omniscience }, // 基准分（%）
  est   // 指数为估算值（可选）
}
```

想更新数据，抓取 `https://artificialanalysis.ai/zh/leaderboards/models` 的 HTML，
按上面的解析步骤取出 `models` 数组，筛掉 `deprecated` 与无 `intelligenceIndex` 的条目，
把 `0-1 的小数 × 100` 转成百分比分后写入 `data.js` 即可（也可直接点页面右上角「刷新数据」在线取最新值）。
